# @sigrun/tui

The sigrun terminal client — a pi-tui based TUI over the sigrun §5 API,
spawned by the sigrun CLI (`sigrun run`), or standalone against a server
URL (`sigrun-tui`). Optional companion of
[@sigrun/sigrun](https://github.com/sigrun-ai/sigrun) (install separately:
`npm i -g @sigrun/tui`).

Part of the sigrun workspace; published from the repository root as
`@sigrun/tui`.
